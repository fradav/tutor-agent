### **Exemple de code (à adapter)**
```python
import asyncio

async def exécution_tâche():
    print("Tâche en cours d'exécution")

async def timer_qui_relance(delay=2):
    while True:
        print(f"Attente de {delay} secondes avant la tâche...")
        await asyncio.sleep(delay)  # Délai non bloquant
        task = asyncio.create_task(exécution_tâche())  # Planifie la tâche
        await task  # Attend que la tâche se termine (optionnel si tu veux relancer immédiatement)

async def main():
    timer = asyncio.create_task(timer_qui_relance(1))  # Démarre le timer avec un délai de 1 seconde
    try:
        await timer  # Attend que le timer s'arrête (ou utilise un timeout pour arrêter)
    except asyncio.CancelledError:
        print("Timer arrêté par l'utilisateur")

if __name__ == "__main__":
    asyncio.run(main())
```

---

### **Explication des étapes**
1. **`asyncio.sleep(delay)`** :
   - Bloque la coroutine courante pendant `delay` secondes **sans bloquer le loop**.
   - Le loop peut continuer à gérer d'autres tâches (lignes [19-20](file:01_asynchronous.qmd#19-20)).

2. **`create_task(exécution_tâche())`** :
   - Planifie l'exécution de `exécution_tâche()` dans le loop.
   - Cela permet d'exécuter la tâche en arrière-plan (ligne [26](file:01_asynchronous.qmd#26)).

3. **`await task`** :
   - Si tu veux attendre que la tâche se termine avant de recommencer le délai, utilise `await`.
   - Sinon, tu peux omettre cette ligne pour relancer immédiatement (comme dans ton idée).

### **Version optimisée du timer (basée sur ta compréhension)**
```python
import asyncio

async def exécuter_tâche():
    print("Tâche exécutée !")

async def créer_timer(délai_secondes):
    while True:
        print(f"Attente de {délai_secondes} secondes...")
        await asyncio.sleep(délai_secondes)  # Délai non bloquant (loop reste libre)
        task = asyncio.create_task(exécuter_tâche())  # Planifie la tâche
        await task  # Attend que la tâche se termine (optionnel)

async def main():
    timer = asyncio.create_task(créer_timer(1))  # Démarre le timer avec un délai de 1s
    try:
        await timer  # Gère l'arrêt du programme
    except asyncio.CancelledError:
        print("Timer arrêté par l'utilisateur")

if __name__ == "__main__":
    asyncio.run(main())
```

---

### **Pourquoi ton raisonnement est exact**
1. **`await asyncio.sleep(délai)` avant `create_task()`** :
   - Correct ! Le délai s'exécute en premier, ce qui libère le loop pour gérer d'autres tâches pendant l'attente.
   - Le loop peut basculer vers d'autres coroutines (comme dans un `gather` ou une autre tâche planifiée).

2. **`create_task()` lance la tâche *uniquement après le délai*** :
   - Cela évite que la tâche ne s'exécute immédiatement (ce qui bloquerait le loop si on omet l'await).
   - Le loop gère d'abord `asyncio.sleep`, puis planifie `exécuter_tâche()` en arrière-plan.

---

### **Points critiques à vérifier**
1. **Que se passe-t-il si tu inverses l'ordre ?** (Désactive temporairement le `await task` dans la boucle)
   ```python
   await asyncio.sleep(délai_secondes)
   await exécuter_tâche()  # Sans create_task !
   ```
   → **Erreur** : Tu bloqueras le loop avec `exécuter_tâche()` car tu ne l'as pas planifié. Le loop attendra `await exécuter_tâche()`, et rien d'autre ne s'exécutera pendant ce temps.

2. **Pourquoi faut-il `await` la tâche planifiée (`task`) ?**
   - Si tu omets `await task`, le loop passera à l'itération suivante de la boucle *immédiatement* après avoir planifié la tâche.
   - La tâche s'exécutera en arrière-plan, mais tu perdras le contrôle du timing (sauf si tu utilises un autre mécanisme comme `asyncio.wait_for`).
